# OpenShapeForge — wekelijkse release notes

Periode: 20 t/m 25 september 2026

Bron: `main` (`origin/main`), uitsluitend de geschiedenis van deze branch in deze periode.

## Wat veranderde er?

- **Betrouwbaardere pakketpublicatie.** Het publiceren van hoofdbranch-pakketten gebruikt nu de geregistreerde lokale runner die bij deze repository hoort. Daardoor kan de controle en publicatie van packages op een vaste, repository-specifieke omgeving plaatsvinden. ([PR #675](https://github.com/OpenShapeForge/OpenShapeForge/pull/675))

## Richting van het product

De vorige editie beschreef vooral een terughoudende release rond de declaratieve Operation-basis. Deze week bevat `main` geen nieuwe eindgebruikersfunctionaliteit, maar wel een stap in de leveringsketen: package-releases worden explicieter aan hun eigen gecontroleerde omgeving gekoppeld. De richting is daarmee tijdelijk meer operationeel dan productmatig: eerst wordt de basis voor voorspelbare distributie aangescherpt, terwijl de bredere Operation- en multi-interfaceontwikkeling buiten deze weekgeschiedenis verdergaat.
